# Evolve Information Architecture

## Primary contexts

- Workspace: organization operations.
- Platform: cross-organization superuser operations.
- Artist portal: curated linked-artist information.
- Developer: scoped API access.
- Django Admin: internal operational administration.

## Workspace navigation

Overview; Artists; Live and operations; Music; Finance (including Rights and Royalty Statements); Content and records; Organization; Platform when authorized; Account.

Desktop uses persistent grouped navigation. Tablet and mobile web use a drawer. Installed mobile uses up to four authorized high-frequency destinations and More. Destination visibility delegates to existing permission data and does not grant access.

Deep links and current route families remain stable. Organization selection is transient UX context and cannot authorize a request.

## Command-centre consolidation

Dashboard consolidates authorized operational signals without becoming a mutation domain. Bookings combine priority and calendar views at their existing route. Music Release lists provide pipeline context. Campaign detail owns its phase responsibility matrix; Rollout remains the execution workspace. Existing deep links and domain boundaries are unchanged.
