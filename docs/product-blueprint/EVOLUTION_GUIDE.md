# Evolve Evolution Guide

## Preserved

All established domain models, migrations, URLs, APIs, authorization rules, operational actions, Django Admin, organization boundaries, and deployment topology remain unchanged.

## Polished

The shared palette, typography, content width, page hierarchy, form/button touch sizes, application shell spacing, and responsive behavior now have explicit system-level definitions.

## Extended

Evolve now has an install manifest, generated branded icon, production service-worker lifecycle, privacy-safe offline fallback, reconnect/update states, safe-area handling, and installed-mobile bottom navigation.

## Merged

No product domains or data models were merged. Existing Finance/Rights navigation grouping remains information architecture only.

## Deprecated

Nothing is deprecated by this work.

## Migration impact

No database model changed and no migration is required.

## Deliberately deferred

This pass does not add push delivery, offline operational data, background sync, binary storage, automatic email, or new product domains. Those require independent architecture and security decisions.
